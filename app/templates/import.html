SAP Stock Report → Reconciliation

Export the SAP actual-stock report with Report output — it comes out as an .html file, not a spreadsheet — and upload it unchanged. Only the Closing Stock column is read; SAP's own opening/receipt/issue columns are ignored, because GRN and Dispatch already hold that and counting both would double up. Quantities in MT are converted to bags using each product's bag size.

Pick the godown and the date yourself: the file doesn't say which godown it is, and its From/To Date columns are 01.01.0000 / 31.12.9999 placeholders rather than a statement date. Re-uploading the same godown and date replaces those figures.
